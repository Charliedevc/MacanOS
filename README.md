# MacanOS

MacanOS is a dual-display infotainment prototype for a 2017 Porsche Macan. The planned v0.6 display modes are independent operation and a unified interface spanning both screens. Third-party control of both NaviRider displays remains unverified.

## v0.5 documentation archive

The [reconstructed engineering report](docs/MacanOS-v0.5-Reports/reports/MacanOS-v0.5-Recreated-Report.md) describes the architecture, historical validation, and hardware compatibility work. The archive also includes PDF, Word, and HTML copies, diagrams, CSV tables, provenance, and SHA-256 checksums.

This initial commit archives documentation. The original application source, Git history, executables, screenshots, and raw test logs were unavailable. Historical test results were carried forward from the prior record. To restore the software baseline, recover a saved checkout, Git bundle, or source archive for the recorded branch `macanos/v0.5` and commit `d6a19ad`.
